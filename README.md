### Featured: [TrailPeak](https://github.com/tinapaaay/trailpeak)

**Find and join Philippine joiner hikes without the DM back-and-forth.** Search by mountain, date, group size and pick-up point, see the real fee, and reserve a slot with a DP. Organizers get one dependable joiner list.

[**Live site**](https://tinapaaay.github.io/trailpeak/) · [Code](https://github.com/tinapaaay/trailpeak) · [Design system](https://github.com/tinapaaay/trailpeak/blob/main/DESIGN.md) · [Architecture decisions](https://github.com/tinapaaay/trailpeak/tree/main/docs/adr)

- **Research first:** started from 27 real posts in a 148K-member hiking group, then a PRD, a backlog, and an assisted pilot plan.
- **Real backend:** Supabase with row-level security, email and Google sign-in, live slots that can't overbook, and joiner details deleted 30 days after a trip.
- **Designed in the open:** a lint-clean `DESIGN.md`, two design critiques, WCAG 2.1 AA checks.
- **Built like a team:** GitHub issues → one PR per issue → ADRs for decisions that matter.

### What I care about

- **Calm, clean interfaces** that let the content do the talking
- **Accessible by default**, because good design works for everyone
- **Built for real Filipino users**, from pick-up points to GCash

### How I work

- **Design system before UI:** every project starts with a `DESIGN.md` of tokens and rules, linted with Google's design.md CLI.
- **Accessible by default:** semantic HTML, keyboard focus, 44px tap targets, screen-reader checks.
- **Decisions written down:** PRDs for *what*, ADRs for *why that way*.

**Tools:** HTML · CSS · JavaScript · Supabase (Postgres) · GSAP · GitHub Pages · Figma
